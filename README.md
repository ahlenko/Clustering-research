# Text Clustering Research

Програма для дипломного дослідження алгоритмів кластеризації природномовних текстів.
Реалізовано:
- простий графічний інтерфейс для запуску експериментів;
- імпорт TXT (один документ у рядку), CSV та JSON;
- TF-IDF, Word2Vec, FastText, Doc2Vec і додатково Sentence-BERT;
- K-Means, ієрархічну кластеризацію, DBSCAN і додаткові алгоритми;
- власний Parallel K-Means: паралельні незалежні ініціалізації з вибором найкращого результату за внутрішньокластерною сумою квадратів;
- параметри K-Means (ініціалізація), ієрархії (linkage), DBSCAN (eps, min_samples), власні стоп-слова та лематизацію;
- вимірювання часу, пікової пам’яті й CPU для кожної комбінації;
- Silhouette, Davies–Bouldin, Calinski–Harabasz; за наявності міток — F1 macro/micro, V-measure, ARI та NMI;
- рекомендацію кількості кластерів за найкращим Silhouette;
- діаграми розсіювання, дендрограму та графік порівняння часу;
- звіти CSV, JSON і HTML, а також JSON-конфігурацію запуску.

## Встановлення
1. Клонуйте репозиторій
2. Встановіть залежності:
    pip install -r requirements.txt
3. Запустіть `python main.py`.
4. У вікні оберіть TXT, CSV або JSON. Для CSV/JSON вкажіть колонку тексту (`text`) і, за наявності, еталонних міток (`label`). Поле «Макс. кількість текстів» дозволяє взяти перші N документів, а порожнє поле — весь файл.
5. Оберіть один або кілька методів, налаштуйте параметри й натисніть «Запустити експеримент».
6. Звіти і графіки з’являться у папці `reports/`.

Кожен запуск зберігається окремо в `reports/experiments/experiment_YYYYMMDD_HHMMSS/`. У цій папці є результати, графіки, конфігурація та файл `manifest.json`. Натисніть «Попередні експерименти…» у програмі, щоб завантажити будь-який збережений запуск без повторного обчислення.

На macOS можна двічі клацнути [Open_Text_Clustering.command](/Users/Папочка з файлікамі/Diploma/program/Open_Text_Clustering.command), щоб відкрити застосунок.

У папці `datasets/` є однаковий демонстраційний набір із 50 україномовних текстів у форматах `demo_texts.txt`, `demo_texts.csv` та `demo_texts.json`.

Для попереднього пакетного сценарію з `config.py` доступна команда:

    python main.py --batch

## Налаштування
У файлі `config.py` можна змінити:
- список векторизаторів та алгоритмів
- кількість повторів для бенчмарку
- параметри візуалізації
- мову препроцесингу
